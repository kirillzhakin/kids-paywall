# Дизайн-спека и pixel perfect

Эталонный фрейм — **390 × 844** (iPhone 14 / webview). Вёрстка mobile-first,
проверена на 360 / 375 / 390 / 430 px. Все цифры ниже измерены в реальном
Chrome (`pnpm shots` → `design/screenshots/metrics.json`), а не взяты на глаз.

## Радиусы, тени, тап-зоны

* Радиусы: 12 / 16 / 22 / 28 px, кнопки и бейджи — pill.
* Тени: карточка `0 2px 10px rgba(30,26,46,.05)`, кнопка `0 8px 20px rgba(106,69,255,.24)`,
  CTA-бар `0 -6px 20px rgba(30,26,46,.07)`.
* Тап-зоны: кнопка CTA — **54 px**, «Восстановить покупки» / «Мои покупки» — **32 px**,
  закрыть — 34 px, карточка тарифа — вся площадь 154 px.

## Состояния экрана

| Состояние | Как выглядит |
| --- | --- |
| `loading` | две skeleton-карточки с shimmer, CTA заблокирована |
| `error` (загрузка тарифов) | красный баннер «Что-то пошло не так» + «Повторить», CTA заблокирована |
| `error` (покупка) | тост + красная подпись под кнопкой, кнопка снова активна |
| `purchasing` | спиннер в кнопке, «Оформляем…», карточки `opacity .62` |
| `success` | зелёная галочка, «Полный доступ открыт!», чек (тариф, сумма, дата, id покупки, устройство), плюшка «Запись сохранена в базе данных», кнопка «Продолжить игру» |
| `restore` | компактная ссылка → тост «Покупки восстановлены» / «Активных покупок не найдено», лист «Мои покупки» со строками из БД |

Скриншоты всех состояний: `design/screenshots/`
(`01-paywall-390-full`, `04-loading`, `05-error`, `06-success`, `07-sheet`, `08-restore`, `09-purchasing`).

## Как воспроизвести замеры

```bash
pnpm shots        # Chrome headless, 360/375/390/430, DPR 2
                  # PNG + design/screenshots/metrics.json
```

Скрипт также проверяет `horizontalOverflow` и статус загрузки шрифтов —
это и есть автоматическая часть проверки pixel perfect.
